Selected work

Rebuilding Find a Cruise

2025

Find a Cruise is the cruise search page and Cruise Critic’s largest source of revenue. I rebuilt it on React Server Components and rolled it out with structured data, indexing rules and revenue tracking in place from day one. Years earlier I’d cut the same page down to a single API call and put full-page caching in front of it.

Price Alerts

2026

Built end to end: fare-drop search queries, signup on ship and itinerary pages, alert emails through Braze and a dashboard for the team. It launched in the US, UK and Australia and started growing the email list in its first weeks. It’s a modern take on the price-drop alerts I first shipped on the PHP platform in 2016.

Bridge, the internal admin app

2024–2026

Much of Bridge is mine: SEO templates for ship, destination and deal pages, port management, sponsored-deal tools, and itinerary and deal feed pipelines moved off cron onto Inngest and Convex with run history, alerting and validation.

Guardrails for AI coding agents

2026

I co-wrote the policy that keeps AI coding agents from deploying, publishing or migrating production, and enforced it with a hook in each agent, so the team can use them freely without risking the live site.

Moving email from ExactTarget to Braze

2023

I built IMS, the user profile service, with Elasticsearch-backed admin search, imported users from ExactTarget, SSO and Auth0, and removed the old ExactTarget code once nothing depended on it.

Tracking, pricing feeds and partners

2014–2026

I built the click and conversion pixel and the revenue reporting behind it, rebuilt client-side tracking as a queued event pipeline, and moved key pixels server-side. I also built the first meta pricing feeds and onboarded 23 partners and vendors, including Virgin Voyages, Viking and Hurtigruten.

How I work

I do my best work owning a hard problem from the first query to the last alert: a revenue-critical page, a migration nobody wants to touch, a pipeline that has to be right every night. I like working closely with a strong lead, co-leading projects and helping teammates along the way.

I care about leaving systems easier to change than I found them, which is why so much of my work has been upgrades: PHP 8 across 12 repositories, Next.js from the Pages Router to the App Router, Jenkins to GitHub Actions, hand-managed AWS to audited Terraform.
