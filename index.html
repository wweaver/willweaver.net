How I work

I do my best work owning a hard problem from the first query to the last alert: a revenue-critical page, a migration nobody wants to touch, a pipeline that has to be right every night. I like working closely with a strong lead, co-leading projects and helping teammates along the way.

I care about leaving systems easier to change than I found them, which is why so much of my work has been upgrades: PHP 7 to 8.5 on the main platform, Next.js from 9.5 to 16 and from the Pages Router to the App Router, Jenkins to GitHub Actions, hand-managed AWS to audited Terraform.

I’ve worked with AI coding agents every day since 2025: Claude Code, Codex and Copilot, often several in parallel with Conductor, with CodeRabbit reviewing pull requests. At Tripadvisor I co-wrote the agent instructions and the guardrails that keep agents from deploying, publishing or migrating production.
